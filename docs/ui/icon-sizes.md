# 次要图标尺寸与功能总览

本文统计除栏目入口（16 枚 `HubIcon`）之外，散布在详情页、招式详情、计算器、
对战资料、列表行等处的**次要图标**：各自承担什么功能、落在什么尺寸档位上。
机制（字体/SVG 双分支、glyph 索引、位图族）见
[icon-font-catalog.md](icon-font-catalog.md)；属性贴纸见
[type-icons.md](type-icons.md)，版本徽章见 [software-icons.md](software-icons.md)。

> **更新（2026-10）**：数值卡 / 计算卡片头已开始换装**实心彩色功能图标套**
> （`FuncIcon` 位图 + 浅彩磁贴），下文中 42px、26px 两档为新样式；其余档位仍是
> 单色字形时代的现状。两套底色语言正随换装收敛。

## 1. 三条资源通道

| 通道 | 内容 | 尺寸决定方式 |
|---|---|---|
| 单色字形 | 通用 UI 图标，H5 内联 SVG / 微信 ttf，双端双写 | 字形用字号，SVG 用 h/w class |
| 静态位图 | 栏目 3D 图标（HubIcon）、**功能彩套（FuncIcon）**、属性贴纸、招式分类贴纸、版本徽章 | `<image mode="aspectFit">` + 容器定尺寸 |
| 加密位图 | 道具图标（itemImage / battleImage 通道） | 同上，加载/404 有同槽回落 |

FuncIcon 与 HubIcon 同构：144×144 @4 PNG，源 SVG 在 `scripts/icons/func/`，
`render-func-icons.mjs` 栅格化；md=30px / sm=20px 两档，只出图不带底。**底色不是手配**：
同一脚本从 SVG 根 fill 取主色、归 5 个色桶（blue/green/gold/red/violet），生成
`func-tiles.css` 的 `.func-tile--*`（同色相浅底渐变 + 深墨 ink），调用点只传桶名。

## 2. 带底托磁贴（彩色容器 + 内部图标）

「磁贴」= 一个圆角色块托一枚白色或深色图标，是次要图标最主要的承载形式。
现状共 6 种规格、两套配色语言并存：

| 规格 | 使用位置 | 容器 / 圆角 | 内部图标 | 底色语言 |
|---|---|---|---|---|
| 48px | 列表行 `ListRow`（资料/功能/我的/设置） | 48 × 48 / 14 | 36 位图；设置页为 24 字形 | **浅彩渐变底 + 深墨图标** |
| 42px | 数值信息卡 `InfoCard`（宝可梦详情身高体重等、招式详情威力命中等） | 42 × 42 / 15 | **FuncIcon 30 位图**（未换装的槽位为 20 字形） | **同色相浅底** `.func-tile--*`（自动生成） |
| 40px | 道具托盘 `ItemIcon` sm、队伍列表行 `TeamListRow` | 40 × 40 / 12–13 | 道具位图 28；通用字形 20 | 道具为中性白灰托盘；队伍行为红色渐变 |
| 32px | 对战资料使用率行、`BattleItemIcon` | 32 × 32 / 10 | 位图 24；回落字形 16 | 按分区上色的饱和渐变底 |
| 26px | 计算卡片头 `CalcCard` / `CalcSideCard`（伤害计算器、能力值计算器） | 26 × 26 / 8 | **FuncIcon 20 位图**（未换装的场地为 16 字形） | **同色相浅底** `.func-tile--*`（自动生成） |
| 112px | 道具托盘 `ItemIcon` lg（详情页主图） | 112 × 112 / 26 | 位图 80；回落字形 48 | 中性白灰托盘 |

磁贴配色分两套来源：ListRow 用 global.css 手维护的 6 色浅彩板；InfoCard / CalcCard
改用 `.func-tile--*`——由渲染脚本按图标主色自动生成的**同色相**浅底（值与 ListRow 板
接近但不相同），ink 深墨同色相。32px 对战行与 40px 队伍行仍是各自的饱和渐变底。

另有两个「无图标」的色块容器：列表行热门样本编号块（48px，金/红/蓝，
`.pokemon-mark--*`）和道具托盘的 shimmer 加载态——形状规格与同族磁贴一致。

## 3. 无底托字形（线性图标直接用）

不带色块，靠 currentColor 融入所在行/按钮，按尺寸分档：

| 档位 | 功能角色 | 典型位置 |
|---|---|---|
| 48px | 空状态主图形 | 空列表、空收藏占位 |
| 28px | 空状态次级图形 | 模拟器未配置占位 |
| 20–21px | 导航与顶部操作 | 导航栏返回/信息、收藏按钮（40px 圆钮内）、形态切换、弹窗关闭、行主图标 |
| 18px | 输入框内图标 | 搜索框放大镜/清除（小屏档，大屏 20） |
| 16px | **最大量档位**：行进给、卡内操作 | 行尾 chevron、折叠箭头、卡内功能字形、密码显隐 |
| 14px | 紧凑控件内 | 筛选 chip、小加号按钮、工具栏内标记 |
| 12px | 标签内清除 | 已选条件 chip 的关闭叉 |

行尾 chevron 是系统中复现最多的图形（列表行、卡片行、选择器、面板全部同款）。

## 4. 位图资源图标（业务图片，非 UI 字形）

| 资源 | 组件 | 展示尺寸 |
|---|---|---|
| 栏目 3D 图标 | `HubIcon` | 48 托盘中 36（详见 catalog） |
| 功能彩套 | `FuncIcon` | 42 托盘中 30（md）/ 26 托盘中 20（sm） |
| 属性贴纸 | `TypeBadgeIcon`（白圆盘承托） | 圆盘 24 / 32 / 44 三档，贴纸占 75% |
| 招式分类贴纸（物理/特殊/变化） | `MoveCard` 内联 | 34 × 32（物理星形更宽，不做正方） |
| 对战道具 / 全道具 | `BattleItemIcon` / `ItemIcon` | 32 托盘（图 24）/ 40、112 托盘 |
| 版本软件徽章 | `PokedexVersionPicker` | 30 × 30 |

位图缺失时统一回落到同族中性字形，托盘尺寸不变，避免行高跳变。

## 5. 按功能角色划分

| 角色 | 形式 | 说明 |
|---|---|---|
| 数值语义标识 | 42px 浅彩磁贴 + 30 FuncIcon 位图 | 信息卡每一项配一枚语义图标（身高、体重、威力、命中……），图标只做扫读锚点，数值本身是主体；未换装槽位仍用 20 字形 |
| 卡片 / 分区标识 | 26px 浅彩磁贴 + 20 FuncIcon 位图 | 卡片头部标题左侧（攻防/招式/宝可梦/六维），场地等未换装处为 16 字形 |
| 列表行主图标 | 48px 磁贴 + 36 位图 | 入口页栏目；设置等无位图页面用 24 字形 |
| 资源缩略图 | 白盘 / 灰托盘 + 位图 | 属性、分类、道具、版本，给透明底原画承托 |
| 行进给与导航 | 16–20px 纯字形 | chevron、返回、关闭、折叠 |
| 行内操作 | 14–20px 纯字形 | 添加、删除、更多、选中勾、搜索、筛选 |
| 状态切换 | 16–21px 纯字形 | 收藏星（线性/实心切换）、密码眼睛、筛选激活态 |
| 空状态 | 28–48px 纯字形 | 居中大图标 + 文案 |

## 6. 刻意不用图标的区域

以下区域以排版/数字本身为视觉主体，不放图标：

- 招式卡的威力 / 命中：等宽数字 + 小号大写标签 + 竖向分隔线
- 计算卡片内的六维能力值、伤害结果数值
- 个体值计算各行（性格增减用 ▲▼ 字符而非图标）
- 对战资料里的使用率百分比与进度条

## 7. 现状问题与收敛方向

- 磁贴规格仍有 6 种、圆角 8–26px 随尺寸漂移；FuncIcon 落地后图槽比已对齐
  （md 71% / sm 77%，PNG 自带 ~7% 透气），但容器侧尚无统一尺寸令牌。
- 底色语言曾两套并存（ListRow 浅彩 vs InfoCard/CalcCard 饱和）：2026-10 换装后
  InfoCard / CalcCard 已改为按图标主色自动生成的同色相浅底（func-tiles.css），
  与 ListRow 手板同为浅彩但来源不同；32px 对战行、40px 队伍行仍是饱和渐变底。
  同组卡片同色相邻时由调用点换桶编排，目前为「同色优先」，不做强对比。
- 纯字形 12–48px 档位多，相邻档位（14/16/18、20/21）接近一个字号，缺令牌约束。
- FuncIcon 套当前仅 12 枚、覆盖数值卡与卡片头；同套设计稿中尚有 hp / evasion /
  sleep / event / item 等候选未启用，蛋群 / PP / 目标 / 场地槽位暂留旧字形。
